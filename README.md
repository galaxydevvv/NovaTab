# Instructions
How to use NovaTab 
1. First save the website url:
```https://galaxydevvv.github.io/ProcrastinationOS/```. 
2. Download a extension from your browser which allows you to set custom newtabs
3. In the settings for the new tab set the website to open on new tab to the url: ```https://galaxydevvv.github.io/ProcrastinationOS/```. 

**CALENDAR SETUP**

1. Open google calendar or your choice of calendar (with embed support)
2. Config the embed however you would like and then copy the raw url
3. Paste the raw url into either the calendar gui or settings menu
4. Refresh to see calendar
