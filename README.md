# Instructions
In order to acess ProcrastinationOS you need to do one of following methods, either install locally or just go to the website.  

**WEBSITE:**
```https://galaxydevvv.github.io/ProcrastinationOS/```. 

**LOCAL INSTALL**
Follow the following steps to locally install ProcrastinationOS to your computer.
1. Go to the github page:
```https://github.com/galaxydevvv/ProcrastinationOS```
2. Fork the repo
3. Start a new codespace in the repo you just forked
4. In the terminal run:
```npm install```
then,
```npm run dev```
5. Then it should show a pop-up to open the local host link, open that
6. Boom you are running ProcrastinationOS locally.
